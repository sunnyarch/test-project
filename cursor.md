# trest - project

This is a **Node.js** app written in **TypeScript**, using **Next.js**.

## Tech stack

- Runtime: Node.js
- Language: TypeScript
- Framework: Next.js

## Working here

- Treat this folder as the project root.
- Use TypeScript for app code; avoid plain JavaScript unless a config file requires it.
- Follow Next.js conventions for routing, pages, and server/client components.
- Prefer small, focused changes.
- Do not commit or push unless the user asks.
